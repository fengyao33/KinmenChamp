## 目前畫面基準(截至 2026-09-20)

| 畫面 | 路由 | 重點 |
| :--- | :--- | :--- |
| 進站頁 | `/` | 手繪 logo 主視覺、標語、「開始探索金門」CTA、底部海浪、三步驟說明、版權列 |
| 遊程選擇頁 | `/choose` | 兩張卡:島轉精選 / AI 客製。手機橫向滑動 + 分頁圓點 |
| 島轉精選遊程列表 | `/routes` | 上架的精選遊程清單(卡片:主題色帶、站點串、時長)。手機橫向滑動 + 圓點。選一條 → 地圖 |
| AI 表單 | `/form` | 天數 / 同行者 / 體驗(複選)/ 自由填答。手機底部有往下捲提示(彈跳箭頭)。送出 → Loading |
| Loading | `/loading` | 分步進度(旋轉太陽),完成自動進地圖 |
| 地圖 | `/map?type=island\|ai&route=<id>` | 三欄:行程時間軸 / OSM 金門地圖 / 在地動態牆。手機收成**底部抽屜**(三段拖曳、行程/動態分頁、點地圖收合)。GPS 小飛機定位(固定在地圖層)。詳情卡(手機從底部滑上、可下拉關閉)。動態牆無限捲動。**遊程編輯器**(見變更紀錄) |

**共用**
- 品牌色:磚紅 `#C63A24` / 海藍 `#1B6FA6` / 日橘 `#F2A03D` / 米白紙地。
- 標語:換個角度看金門,換種方式玩金門。
- 假資料集中在 `src/data/mock.ts`(店家、遊程 `curatedRoutes`、動態牆 `feed`)。
- 響應式:電腦、手機都需支援。

## 變更紀錄

### 2026-09-20 建立基準
- 建立本文件,記錄旅客端目前六個畫面與其行為(如上基準表)。

### 2026-09-20 用詞統一:店家 → 商家
- 畫面:地圖頁搜尋框提示「搜尋地點或店家 → 搜尋地點或商家」;動態牆/AI 評論摘要內文的「店家」字樣一併改「商家」。
- 為什麼:全站統一用「商家」,和後台一致。

### 2026-09-20 地圖頁:新增「遊程編輯器」+ 交通方式選擇
- 畫面:地圖頁(桌機左欄 / 手機底部抽屜),桌機與手機都做,沿用原本 UI/UX 與無障礙。
- 改了什麼:行程從唯讀改成可即時編輯,地圖同步更新路線與序號。
  1. 進入編輯:行程標題旁「編輯」按鈕 → 進編輯模式;底部有「儲存為我的行程」「完成編輯」。
  2. 排序:每站左側把手長按拖曳調整順序(滑鼠/觸控皆可)。
  3. 每站選單(⋮):編輯停留時間(±5 分鐘的視窗)、更換地點、從行程移除。
  4. 加入地點:任兩站之間與最後都有「加入地點」,開啟可搜尋的景點清單挑選。
  5. 地圖點選:點地圖上的推薦點會跳詳情卡,顯示「距離路線約 N 公尺」「加入後約 +N 分鐘」,可直接「加入行程」。
  6. 交通方式:每段路線可選「步行 / 單車 / 開車」,系統依直線距離與各方式速度即時算出到下一站的分鐘數,總時數(停留 + 移動)一起更新。
  7. 重新規劃:改成下拉選單,提供「重新規劃行程」與「保留地點,重新排順序」(最近點排序)。
  8. 儲存:「儲存為我的行程」存到瀏覽器本地(`dz_my_trip`),編輯不覆蓋原始推薦行程。
- 為什麼:讓旅客能把推薦行程改成自己的版本;交通方式選擇讓移動時間可計算、總時程更準。
- 註:目前為前端原型,交通時間用直線距離估算(非真實路網),之後可接路線規劃 API。

### 2026-09-20 遊程編輯器:依回饋微調
- 交通方式三選項改為「步行 / 機車 / 開車」(原「單車」改「機車」)。
- 「儲存為我的行程」從編輯頁移到檢視(完成)頁:編輯模式底部只留「完成編輯」;非編輯狀態的行程下方才有「儲存為我的行程」。
- 「在地動態牆」文案改「網路動態牆」(手機分頁同步改「網路動態」)。
- 地圖點選的景點詳情卡:只保留「加入行程」(移除「查看詳情」);非行程內的景點不顯示「約 N 分鐘 / 加入後 +N 分鐘」,只留「距離路線約 N 公尺」。
- 「重新規劃」取消下拉選單,恢復單純回到「你想怎麼玩金門」選擇頁。

### 2026-09-25 新增「創意排行榜」
- 入口:首頁右上角「創意排行榜」按鈕 → `/leaderboard`。
- 排行榜:依票數排名(同票較早投稿在前),前三名有皇冠與獎牌色;可切換「票數最高 / 最新上傳」;點卡片看詳情(照片輪播、作者、說明、投票)。
- 投票:每則路線每台裝置一票,再按一次可收回(原型用瀏覽器本地記錄)。
- 上傳視窗:遊程名稱(必填,30 字)、創意說明(必填,300 字)、暱稱(選填,不填顯示匿名旅人)、照片(必填 1~5 張,JPG/PNG/WebP,單張 15MB 內,自動壓縮,第一張當封面,可移除)。
- 個資告知:上傳視窗內有「個人資料蒐集告知事項」區塊(可捲動閱讀)+ 必勾同意才能送出。**條款內容待提供**,置入位置在 `src/content/privacyTerms.ts`(已依個資法第 8 條告知事項排好五段標題)。
- 送出後自動切到「最新上傳」並標示「我的投稿」。
- 追加(同日):上傳視窗新增「聯絡電話」(必填,台灣手機或市話,可輸入 +886、空白、橫線,存檔時統一成 09 開頭格式),欄位下註明「只給島轉官方人員聯繫活動用,不會公開顯示」;前台任何畫面都不顯示電話。
- 追加(同日):未勾選個資同意時,「送出參賽」按鈕鎖住(灰色),上方提示「請先勾選同意個人資料蒐集告知事項,才能送出」。
- 追加(同日):標題、說明、「上傳我的路線」按鈕、排序切換整塊改成吸頂,捲動清單時固定在頂列下方,手機與電腦相同。

### 2026-09-25 地圖頁:快速上傳到創意排行榜
- 畫面:地圖頁頂列右上,「重新規劃」左邊新增「上傳排行榜」按鈕。
- 改了什麼:點擊在地圖頁直接彈出上傳視窗(與排行榜頁同一個表單),**不跳轉頁面**,旅客剛編輯的遊程不會被刷新。視窗頂部提示「可以先截圖你的遊程畫面,當作照片上傳」;不自動附上路線,由旅客自行截圖上傳。送出後跳提示「已上傳到創意排行榜」,人仍留在地圖頁。
- 為什麼:目前匿名、行程只存在畫面上,若導去排行榜頁再回來,編輯過的遊程會消失。
- 追加(同日):排行榜頁的「上傳我的路線」視窗頂部也加上同一句提示「可以先截圖你的遊程畫面,當作照片上傳」,兩個入口一致。

### 2026-09-25 地圖頁:行程自動存在這台裝置
- 機制:地圖頁的「目前行程」(含編輯後的站點、停留時間、交通方式)自動存在瀏覽器本地(`dz_current_trip`),匿名也適用。重新整理、去排行榜、按返回、關掉再開,回到地圖都會還原。
- 覆蓋時機:只有「遊程列表選一條路線」或「AI 生成完成」真正產生新遊程時,才用新遊程覆蓋。其他任何方式回到地圖都還原存檔。
- 恢復:行程有改過時,清單下方出現「已自動存在這台裝置」+「恢復成推薦行程」(會先跳確認「你做的修改會全部還原成原本推薦的行程」)。桌機左欄、手機抽屜都有。
- 關鍵提醒彈窗:行程有改過時按「重新規劃」,先跳「要重新規劃嗎?」說明「改過的行程已自動存在這台裝置;選了新路線或讓 AI 重新生成後,會被新的遊程取代」,按鈕「留在這裡 / 重新規劃」。沒改過則不打擾,直接前往。

### 2026-09-25 地圖頁:交通方式改為整趟一種,放在完成頁
- 交通方式從「每段各自選」改成「整趟行程選一種」(步行 / 機車 / 開車),因為路線演算法一次只能用一種交通工具。
- 位置:完成(檢視)頁,行程標題下方的「交通方式」三選一;編輯頁不再出現交通方式選項,各段只顯示「步行 8 分鐘到下一站」這類文字。桌機與手機都有。
- 切換後每段移動時間與總時數即時重算;選擇會跟著行程一起存在這台裝置。預設用推薦路線原本的交通方式。
- 編輯頁的「加入地點」只留每個景點下方那一個,移除最底部多出的一個。

### 2026-09-25 從其他頁回到「我的行程」
- 問題:旅客編輯完行程後回首頁或去排行榜,沒有明顯的路回到地圖;而且從首頁走「開始探索金門 → 選路線」會直接蓋掉改過的行程。
- 首頁:這台裝置有存著的行程時,「開始探索金門」下方多一顆「繼續我的行程:(行程名稱)」,點了直接回地圖(不產生新遊程)。
- 排行榜頁:有存著的行程時,頂列右側出現「我的行程」,點了回地圖。
- 覆蓋前提醒:在「遊程列表選路線」或「AI 表單按生成我的路線」時,若目前行程有改過,先跳「要用新遊程取代嗎?」,說明「你改過的『(行程名稱)』還存在這台裝置;產生新的遊程後就會被取代」,按鈕「回到我的行程 / 用新遊程取代」。沒改過則不打擾。
- 技術:目前行程的存取抽成 `src/data/trip.ts`,地圖頁、首頁、排行榜、遊程列表、AI 表單共用。

### 2026-09-25 地圖標記改成風獅爺
- 行程站點:改用「風獅爺小弟」圖,右上角保留站序號碼(選中時放大、號碼變日橘色),腳底對準座標,永遠疊在其他標記上面。
- 非行程但我們標註的景點:改用「風獅爺石雕」圖。
- 地圖底圖原本的圖示(廟宇、學校、公車站等)不動。GPS 我的位置藍點不動。
- 效能:原圖每張 1.5 到 2.3MB,另外縮成地圖專用小圖(約 50KB)放在 `public/markers/`,原圖保留不動。
- 註:目前資料存在瀏覽器本地,接後端時需補:投票防灌票(登入或裝置驗證)、投稿審核、檢舉機制、照片上傳到雲端儲存。
