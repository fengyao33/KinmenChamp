## 目前畫面基準(截至 2026-09-20)

| 畫面 | 路由 | 重點 |
| :--- | :--- | :--- |
| 進站頁 | `/` | 手繪 logo 主視覺、標語、「開始探索金門」CTA、底部海浪、三步驟說明、版權列 |
| 遊程選擇頁 | `/choose` | 兩張卡:島轉精選 / AI 客製。手機橫向滑動 + 分頁圓點 |
| 島轉精選遊程列表 | `/routes` | 上架的精選遊程清單(卡片:主題色帶、站點串、時長)。手機橫向滑動 + 圓點。選一條 → 地圖 |
| AI 表單 | `/form` | 天數 / 同行者 / 體驗(複選)/ 自由填答。手機底部有往下捲提示(彈跳箭頭)。送出 → Loading |
| Loading | `/loading` | 分步進度(旋轉太陽),完成自動進地圖 |
| 地圖 | `/map?type=island\|ai&route=<id>` | 三欄:行程時間軸 / OSM 金門地圖 / 在地動態牆。手機收成**底部抽屜**(三段拖曳、行程/動態分頁、點地圖收合)。GPS 小飛機定位(固定在地圖層)。詳情卡(手機從底部滑上、可下拉關閉)。動態牆無限捲動 |

**共用**
- 品牌色:磚紅 `#C63A24` / 海藍 `#1B6FA6` / 日橘 `#F2A03D` / 米白紙地。
- 標語:換個角度看金門,換種方式玩金門。
- 假資料集中在 `src/data/mock.ts`(店家、遊程 `curatedRoutes`、動態牆 `feed`)。
- 響應式:電腦、手機都需支援。
