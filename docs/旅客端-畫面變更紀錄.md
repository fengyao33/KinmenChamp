## 變更紀錄

### 2026-09-20 建立基準
- 建立本文件,記錄旅客端目前六個畫面與其行為(如上基準表)。

### 2026-09-20 用詞統一:店家 → 商家
- 畫面:地圖頁搜尋框提示「搜尋地點或店家 → 搜尋地點或商家」;動態牆/AI 評論摘要內文的「店家」字樣一併改「商家」。
- 為什麼:全站統一用「商家」,和後台一致。

### 2026-09-20 地圖頁:新增「遊程編輯器」+ 交通方式選擇
- 畫面:地圖頁(桌機左欄 / 手機底部抽屜),桌機與手機都做,沿用原本 UI/UX 與無障礙。
- 改了什麼:行程從唯讀改成可即時編輯,地圖同步更新路線與序號。
  1. 進入編輯:行程標題旁「編輯」按鈕 → 進編輯模式;底部有「儲存為我的行程」「完成編輯」。
  2. 排序:每站左側把手長按拖曳調整順序(滑鼠/觸控皆可)。
  3. 每站選單(⋮):編輯停留時間(±5 分鐘的視窗)、更換地點、從行程移除。
  4. 加入地點:任兩站之間與最後都有「加入地點」,開啟可搜尋的景點清單挑選。
  5. 地圖點選:點地圖上的推薦點會跳詳情卡,顯示「距離路線約 N 公尺」「加入後約 +N 分鐘」,可直接「加入行程」。
  6. 交通方式:每段路線可選「步行 / 單車 / 開車」,系統依直線距離與各方式速度即時算出到下一站的分鐘數,總時數(停留 + 移動)一起更新。
  7. 重新規劃:改成下拉選單,提供「重新規劃行程」與「保留地點,重新排順序」(最近點排序)。
  8. 儲存:「儲存為我的行程」存到瀏覽器本地(`dz_my_trip`),編輯不覆蓋原始推薦行程。
- 為什麼:讓旅客能把推薦行程改成自己的版本;交通方式選擇讓移動時間可計算、總時程更準。
- 註:目前為前端原型,交通時間用直線距離估算(非真實路網),之後可接路線規劃 API。

### 2026-09-20 遊程編輯器:依回饋微調
- 交通方式三選項改為「步行 / 機車 / 開車」(原「單車」改「機車」)。
- 「儲存為我的行程」從編輯頁移到檢視(完成)頁:編輯模式底部只留「完成編輯」;非編輯狀態的行程下方才有「儲存為我的行程」。
- 「在地動態牆」文案改「網路動態牆」(手機分頁同步改「網路動態」)。
- 地圖點選的景點詳情卡:只保留「加入行程」(移除「查看詳情」);非行程內的景點不顯示「約 N 分鐘 / 加入後 +N 分鐘」,只留「距離路線約 N 公尺」。
- 「重新規劃」取消下拉選單,恢復單純回到「你想怎麼玩金門」選擇頁。

### 2026-09-25 新增「創意排行榜」
- 入口:首頁右上角「創意排行榜」按鈕 → `/leaderboard`。
- 排行榜:依票數排名(同票較早投稿在前),前三名有皇冠與獎牌色;可切換「票數最高 / 最新上傳」;點卡片看詳情(照片輪播、作者、說明、投票)。
- 投票:每則路線每台裝置一票,再按一次可收回(原型用瀏覽器本地記錄)。
- 上傳視窗:遊程名稱(必填,30 字)、創意說明(必填,300 字)、暱稱(選填,不填顯示匿名旅人)、照片(必填 1~5 張,JPG/PNG/WebP,單張 15MB 內,自動壓縮,第一張當封面,可移除)。
- 個資告知:上傳視窗內有「個人資料蒐集告知事項」區塊(可捲動閱讀)+ 必勾同意才能送出。**條款內容待提供**,置入位置在 `src/content/privacyTerms.ts`(已依個資法第 8 條告知事項排好五段標題)。
- 送出後自動切到「最新上傳」並標示「我的投稿」。
- 註:目前資料存在瀏覽器本地,接後端時需補:投票防灌票(登入或裝置驗證)、投稿審核、檢舉機制、照片上傳到雲端儲存。
