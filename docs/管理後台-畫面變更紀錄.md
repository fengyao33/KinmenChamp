## 目前畫面基準(截至 2026-09-20)

後台程式全部在 `src/admin/`,路由 `/admin/*`,與前台分離。設計目標:**白癡都會用 + 無障礙**。

| 畫面 | 路由 | 重點 |
| :--- | :--- | :--- |
| 登入 / 開新帳號 | `/admin/login` | 原型登入(任意帳密進),尚未接真帳號系統 |
| 總覽 | `/admin` | 數字卡(上架店家/遊程、活動優惠、表單題數)+ 快速入口 |
| 店家管理 | `/admin/stores` | Google Place 匯入 + 列表 + **編輯特色/分類/上下架** + 綁定活動優惠 + 搜尋 |
| 活動與優惠 | `/admin/offers` | 新增/刪除優惠或活動,綁定到店家 |
| 遊程編排 | `/admin/routes` | 挑店家、↑↓排序、上下架,存成精選遊程 |
| AI 表單設計 | `/admin/form` | 題目/選項增刪、↑↓排序、單選/複選/自由填答 |
| 評論與旅遊資訊 | `/admin/insights` | 切換器(店家評論 / 旅遊資訊),檢視 + 手動重抓爬蟲 |

**共用**
- 側邊選單(電腦)/ 漢堡抽屜(手機);每頁有標題 + 一句白話說明 + 明確主要按鈕 + 空狀態。
- 無障礙:44px 觸控目標、`<label>` 綁定、`role`/`aria`、Esc 關閉、操作後 toast 回饋。
- 假資料 + localStorage:`src/admin/data.ts`(種子取自前台 mock);原型登入:`src/admin/auth.ts`。
- 響應式:電腦、手機都需支援。
